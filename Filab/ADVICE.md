# Filab 后续建议

## 0. 当前执行边界

这一轮先不做“胶片预设作为独立数据文件保存”、不做完整数据驱动胶片系统，也不迁移 3D LUT 管线。当前策略是继续维护现有内置预设结构，在这个结构里微调胶片观感、增强 Adjust、导出和相册能力。

本轮已完成：

- Adjust 新增白色色阶、黑色色阶、锐化、HSL、色调、柔光、Halation、Fade、颗粒大小、颗粒粗糙和彩色颗粒。
- 新增的 Adjust 参数已经接入 Metal 轻量 adjust pass，滑块调整仍然叠加在缓存的胶片结果上。
- Core Image fallback 已做对应近似处理，保证 Metal 不可用时仍能输出。
- Adjust 页面重组为调光、颜色、HSL、色调、效果、颗粒，并支持单个滑块双击或长按重置。
- HSL 已改成先选颜色通道，再调色相、饱和、明度，避免一页塞满 24 个滑块。
- 柔光和红色光晕已降低强度并重做混合，避免 100% 时出现过重或重影。
- 精修了 Portra 400、Gold 200、Fuji Pro 400H、CineStill 800T、HP5、Polaroid、Ricoh GR 等现有内置预设。
- 导出新增 JPEG / HEIF / PNG 格式选择，JPEG 和 HEIF 会真正使用导出质量设置。
- 自动保存开关已经真正接入编辑器关闭流程。
- 首页相册新增搜索、按胶片预设筛选、选择模式和批量删除。

## 1. 让胶片系统更准确

现在的预设更像是手工调出来的 film look，已经有方向感，但还不是严格意义上的胶片色彩科学系统。以后如果想做成完整胶片系统，建议逐步改成数据驱动：

- 短期不要急着拆独立数据文件，继续先把现有内置预设调准。
- 等预设数量和校准资料明显增加后，再考虑给预设加版本字段，比如 `presetVersion`、`source`、`calibrationNotes`。
- 3D LUT 可以作为长期目标，不是当前优先级。
- 建一组固定测试图：肤色、日光风景、夜景霓虹、过曝高光、深阴影、黑白人像。
- 每次调整胶片参数都用同一组测试图对比，避免某个场景好看但另一个场景崩掉。

优先精修这些预设：

- Kodak Portra 400：肤色、高光肩部、轻微暖调。
- Kodak Gold 200：消费级暖色负片感，但不要整体过橙。
- Fuji Pro 400H：通透高光、轻微绿青调、低反差。
- CineStill 800T：钨丝灯平衡、青色阴影、亮点周围红色 halation。
- Ricoh Positive Film：高对比高饱和，但不要把阴影全部压死。
- Ilford HP5：真正的黑白影调分离和更有性格的颗粒。

## 2. 继续增强 Adjust 页面

Adjust 页面的核心感觉应该是：先选中一款胶片，然后所有调整都叠加在这款胶片底片之上。

建议保持这个模型：

- Film pass：胶片身份，包括色彩响应、曲线、内置颗粒、halation、bloom、fade、暗角。
- Adjust pass：用户调整，包括曝光、对比、高光、阴影、色温、色调、饱和度、清晰度、暗角、颗粒量、柔光、胶片强度。
- Export pass：用同一套效果栈重新渲染原图全分辨率。

建议新增的调整项：

- 白色色阶和黑色色阶。
- 锐化，和清晰度分开。
- HSL：红、橙、黄、绿、青、蓝、紫、洋红。
- 阴影/高光分离色调。
- 颗粒大小、粗糙度、彩色颗粒、高光颗粒衰减。
- Halation 强度和半径。
- 柔光阈值和强度。
- Fade 颜色，而不只是 fade 数值。
- 给高级用户的曲线编辑器。

交互建议：

- 每个调整项支持长按重置。
- 滑块双击重置单个参数。
- 图片区域任意位置长按都可以看原图，不只依赖眼睛按钮。
- 滑块拖动时不要显示阻塞式 loading；导出这种明确耗时动作可以显示进度。
- 支持保存自己的胶片配方。

## 3. 把相册做成真正的图库系统

Filab 很自然会从一次性滤镜工具变成胶片照片系统。建议下一步补：

- 相册或合集。
- 收藏。
- 最近编辑。
- 按胶片预设筛选。
- 按预设名、日期、备注搜索。
- 复制一个旧编辑，然后尝试另一款胶片。
- 重新打开旧作品，并恢复原图、胶片和全部调整参数。
- 多张照片批量套用同一个预设。
- 选中一个相册批量导出 JPEG。

存储方面，早期用 `UserDefaults` 加图片文件可以，但如果相册系统继续变复杂，建议迁移到 SwiftData 或其他轻量数据库。

## 4. 升级导出能力

导出应该清晰、可信、可控：

- JPEG 质量选择：已经很有必要，继续保留。
- 增加 HEIF 导出。
- 只有在需要无损时才提供 PNG。
- 开启“保留元数据”时真正保留 EXIF。
- 加入色彩空间处理，例如 Display P3 和 sRGB。
- 增加导出尺寸选项：预览尺寸、原图尺寸、自定义长边。
- 水印只作为可选导出模式，不要默认影响原图导出。

## 5. 性能路线

最重要的性能原则：用户拖动普通调整滑块时，不要重新计算完整胶片模拟。

建议保持：

- 预览纹理小于原图。
- 只有源图或预设变化时才重新计算胶片底片。
- 滑块变化只跑 adjust pass。
- 导出或最终保存时再跑全分辨率渲染。
- 避免在 MainActor 上阻塞读回 Metal 纹理。
- 真机上用 Instruments 测滑块拖动，不只看模拟器。

未来可以继续优化：

- 用 `MTKView` 直接显示 GPU 结果，而不是每帧转成 `UIImage`。
- 编辑会话期间持续保留 GPU 纹理。
- 曲线改用 lookup texture。
- Halation 和 bloom 使用 separable blur 或 mip-chain。

## 6. 产品方向

Filab 最强的形态应该是一个现代胶片暗房，而不是普通滤镜 app。

理想工作流：

- 选择照片。
- 选择胶片。
- 精细调整。
- 保存成自己的配方。
- 在相册中管理。
- 用可控质量导出。
- 之后还能重新打开继续编辑。

长期目标：让用户感觉这是一个完整的胶片影像系统，而不是一组简单滤镜。
